**GLOBAL DISTRIBUTED TEAM OPERATING CHARTER**  
*Communication, Collaboration & Conflict Resolution Framework for Multinational Technology Teams*  
**Executive Edition — Version 3.1**

---

## EXECUTIVE SUMMARY

Geographically dispersed project teams incur a **15–20% velocity penalty** from coordination overhead: ambiguous handoffs, timezone latency, and culturally mismatched conflict avoidance. For a multinational technology company, this is a unit-economics issue—not merely an HR concern. It manifests as slipped release dates, attrition in non-headquarters hubs, and compliance exposure across GDPR, PIPL, and emerging AI governance regimes.

This charter establishes a **120-day Pilot-to-Scale program** to deploy an async-first, culturally fluent, and legally compliant operating system. Rather than mandating identical rituals globally, it mandates **equivalent outcomes**: transparency, psychological safety, predictable velocity, and full regulatory compliance.

### Program Dashboard

| Strategic Objective | Target Metric | Resource Requirement |
|---------------------|---------------|----------------------|
| **Accelerate Decision Velocity** | 40% reduction in Mean Time To Decision (MTTD) via permanent, searchable documentation | 0.5 FTE Automation Engineer (60-day contract); Slack/Teams bot framework; ~$25K |
| **Reclaim Synchronous Capacity** | 30% reduction in meeting load while maintaining decision quality | Transcription licenses; digital canvas enterprise licenses; facilitator training; ~$30K |
| **Contain Conflict & Protect Culture** | 50% reduction in formal HR escalations from distributed teams; 85% of conflicts resolved within 72 hours | 10% protected FTE per Cultural Liaison; liaison recognition stipends; ~$15K |
| **Ensure Regulatory Zero-Defect** | Zero data-residency or shadow-IT violations post-launch | 0.5 FTE Legal counsel; 0.25 FTE IT Security architect; regional cloud tenancy upgrades; ~$35K |
| **Close Infrastructure Gaps** | 100% of hub staff equipped for Tier A/B/C participation within 30 days | Noise-canceling headsets and HD webcams for all hubs; mobile/offline tool licenses; bundled in procurement |

**Total Estimated Pilot Investment:** ~$105K  
**Target ROI:** Break-even within one quarter via recovered sprint capacity and reduced attrition in distributed hubs.

## STRATEGIC PRINCIPLES

1. **Async-First:** Synchronous time is expensive and cognitively taxing for non-native speakers; live interaction is reserved for debate, relationship repair, and complex negotiation.
2. **Topology-Aware:** Overlap mathematics vary by squad. A Tier 3 (zero-overlap) team requires a fundamentally different operating system than a Tier 1 (high-overlap) team.
3. **Individual Over National:** Cultural calibration is based on self-assessed personal profiles, not passport-based stereotyping.
4. **Enforceable, Not Aspirational:** Every norm carries an owner, an audit mechanism, and a calibration loop for decay.

## I. GOVERNANCE, PRIVACY & INFRASTRUCTURE

Operational norms cannot function without legal and technical scaffolding. This section must be satisfied before any squad launches.

### A. Data Residency & Privacy Architecture

| Data Type | Residency Requirement | Retention | Access Control |
|-----------|----------------------|-----------|----------------|
| **Auto-transcriptions & Recordings** | Region-of-origin cloud (EU: GDPR zone; China: PIPL zone) | 90 days unless designated permanent | Host + invitees only; AI training opt-out mandatory |
| **“Working With Me” Manuals** | HR-sensitive; local People Ops infrastructure | Employment + 1 year | Individual, manager, HRBP |
| **Decision Logs / ADRs** | Project metadata only; no personal data | Permanent | Public within project |
| **Conflict Mediation Records (Tiers 2–4)** | Jurisdiction of legal entity; encrypted at rest | Per local labor law (3–7 years) | HR, Legal, Ombuds only |
| **Calendar Metadata** | Contextual transparency is **opt-in**; default is “availability only” | Standard policy | Individual controls granularity |

**Rationale:** Multinational collaboration artifacts cross borders by default. Storing transcripts or personal disclosures in a centralized, non-compliant stack creates liability.  
**Expected Outcome:** Defensible audit trail; zero regulatory findings.

### B. Shadow IT Prohibition
All messaging bridges (e.g., WhatsApp, WeChat Work, Lark) must pass data-loss prevention and data-residency review and integrate via sanctioned APIs. Unsanctioned backchannels are prohibited for work decisions.

**Rationale:** Regional tool preferences are real, but fragmented channels fragment the source of truth and expose the company to surveillance and data-exfiltration risks.  
**Expected Outcome:** Unified, searchable institutional memory.

### C. Infrastructure Equity

| Bandwidth Tier | Live Participation Protocol |
|----------------|----------------------------|
| **Tier A (High)** | Full video + screen share + digital canvas |
| **Tier B (Limited)** | Audio + screen share; video disabled |
| **Tier C (Low/Cellular)** | Async audio note + chat; no live video requirement |

All primary tools must offer offline-first mobile apps. Procurement specs must include noise-canceling headsets and HD webcams for all hubs, not only headquarters. Facilitators must explicitly state at every meeting start: *“Video is optional for connectivity or privacy needs.”*

**Rationale:** Assuming universal high-bandwidth access excludes talent in emerging hubs and caregivers on cellular connections.  
**Expected Outcome:** Zero team members excluded from ceremonies due to infrastructure inequality.

## II. ASYNCHRONOUS COMMUNICATION PROTOCOLS

*Principle: In a distributed team, communication must be permanent, searchable, timezone-agnostic, and linguistically accessible.*

### A. Channel Hierarchy & Purpose
A strict, security-approved tool stack eliminates ambiguity about where information lives.

| Channel | Purpose | Response Time | Retention |
|---------|---------|---------------|-----------|
| **Ticketing / Project Mgmt** | Task status, acceptance criteria, sprint work | 24 business hours | Permanent |
| **Knowledge Base** | Decisions, RFCs, architecture docs, retrospectives | N/A (pull-based) | Permanent |
| **Async Messaging** (Public Channels) | Questions, alignments, blockers | 24 business hours | 90 days |
| **Direct Messages** | Sensitive topics, 1:1 coaching, face-saving clarification | 24 business hours | 90 days |
| **Email** | External stakeholders, formal announcements | 48 business hours | Permanent |
| **Voice/Video** (Loom/Zoom) | Relationship building, complex negotiation | Scheduled only | N/A |

### B. The 24-Hour Backfill Rule
*If a decision is made in a DM or meeting, the decision-taker has 24 hours to backfill it into the public Knowledge Base or project ticket. If it is not documented, it did not happen.*

- **Automation:** Deploy a Slack/Teams bot that detects decision keywords (“decided,” “agreed,” “final call”) in DMs and prompts public backfill.
- **Audit Owner:** The project’s Tech Lead or Scrum Master conducts a weekly decision-log audit.
- **Consequence:** A missed backfill triggers a gentle public reminder; three misses in a sprint trigger a manager 1:1 calibration.

**Rationale:** Decisions trapped in DMs or memory create recurrent “where is that decision?” escalations that stall downstream work.  
**Expected Outcome:** >95% of decisions documented within 24 hours; 50% reduction in manager interventions to reconstruct prior agreements.

### C. The 3-State Urgency Model
Eliminate the expectation of instant response across time zones.

- **P0 – Blocker:** Production outage, security incident, or critical path halt. **Action:** Page/phone during waking hours; escalate to on-call if unavailable.
- **P1 – Standard:** Workflow questions, code reviews. **Action:** Async message/ticket; response within **24 business hours**.
- **P2 – Ambient:** FYIs, brainstorming. **Action:** Post in public channel; no SLA.

**Rationale:** Without explicit urgency taxonomy, every request becomes an implicit demand for immediate attention, driving burnout and after-hours leakage.  
**Expected Outcome:** Predictable response cadence; measurable reduction in off-hours interruptions.

### D. Language Equity Standards
- **BLUF (Bottom Line Up Front):** State the request or conclusion in the first sentence; context follows.
- **Ban Idioms & Phrasal Verbs:** Replace “touch base,” “hold off,” “run by,” and “table the discussion” with literal language.
- **Timestamp Everything:** Use absolute times in UTC. Never use “tomorrow” or “end of day” without specifying whose day.
- **Structured Formatting:** Headers, bullet points, and checkboxes are mandatory. Walls of text disproportionately burden non-native and neurodivergent readers.
- **Acronym Glossary:** Maintain a living wiki page; assume zero fluency in internal jargon.
- **Translation Grace Period:** Allow 48 hours before requiring feedback on complex RFCs.

**Rationale:** Linguistic friction is a tax paid disproportionately by non-native speakers; it compounds into misalignment and slower delivery.  
**Expected Outcome:** Faster comprehension, fewer misaligned deliverables, and broader participation in technical debate.

### E. End-of-Day (EOD) Handoff Protocol
Each handoff-dependent team member posts a brief update before signing off:

1. **Shipped Today:** Completed work, merged PRs, closed tickets.
2. **Dependencies / Input Needed:** Frame as collaboration (*“awaiting your expertise on X”*), not failure, to protect face in high power-distance contexts.
3. **Next Owner:** The explicit task or decision the incoming teammate should own.
4. **ETA / Response Needed:** Tag the specific person and state the question clearly.

**Charter Feedback Loop:** If the squad finds the handoff becomes noise rather than signal, the Scrum Master may reduce frequency (e.g., blockers-only) by documented team consensus.

**Rationale:** Compresses the follow-the-sun cycle and prevents timezone gaps from becoming 24-hour stalls.  
**Expected Outcome:** Seamless timezone transitions with zero ambiguity about baton ownership.

## III. SYNCHRONOUS MEETING OPTIMIZATION

*Principle: Live time is expensive and cognitively taxing; it is reserved for high-bandwidth debate, relationship repair, and complex problem-solving.*

### A. The Overlap Decision Tree
Before scheduling any recurring live ceremony, calculate the squad’s actual overlap.

| Topology Tier | Overlap Condition | Live Collaboration Protocol |
|---------------|-------------------|----------------------------|
| **Tier 1: High Overlap** | ≥3 hours shared business hours | Core overlap window reserved for live collaboration; ROTATE+ applies. |
| **Tier 2: Compressed Overlap** | 1–3 hours shared | Live window reserved for high-stakes decisions only; status and planning move async. Rotate pain monthly. |
| **Tier 3: Zero Overlap** | <1 hour or no shared business hours (e.g., PST ↔ JST) | **Follow-the-Sun Strict Handoff.** No recurring live standups or plannings. All ceremonies async. Live meetings require 48-hour opt-in with comp time. |

**Rationale:** The blanket recommendation of a 3–4 hour “ideal overlap” is mathematically impossible for common global hub pairings. Tier 3 squads are not exceptions; they require a distinct architecture.  
**Expected Outcome:** Realistic scheduling that respects physiology rather than forcing chronic night-shift heroics.

### B. The ROTATE+ Framework (Tier 1 & 2 Only)
All synchronous meetings must satisfy **at least four** of the following criteria:

- **R**otated Times: Rotate recurring meetings monthly if spanning >8 time zones. Track burden with a **Pain Score** (1 point per 30 minutes outside 7 AM–7 PM local). Rebalance when the inter-regional delta exceeds 4 points. *Owner: Engineering Manager maintains a public scorecard.*
- **O**bjective First: The desired outcome is stated in the calendar invite title.
- **T**imeboxed: Default to 25 or 50 minutes.
- **A**genda + Pre-read: Distributed 48 hours in advance. **No pre-read = meeting cancelled** (emergency P0 blockers excepted).
- **T**ranscribed & Recorded: Auto-transcription enabled; backup note-taker assigned if non-Roman script languages are primary. Link posted within 1 hour.
- **E**quity Check: Facilitator explicitly calls on quieter participants; a second person monitors chat to surface written questions.

**+ Facilitator Calibration:** Facilitators complete a 30-minute self-paced module on linguistic turn-taking and display the **Facilitator Card** (Appendix D) on-screen. Speaking pace target: ~130 words per minute, with a 7–10 second pause after each question.

**Rationale:** Without rotation and measurement, one region bears the cognitive and social cost of antisocial hours indefinitely. Without calibration, non-native and introverted participants are systematically excluded from debate.  
**Expected Outcome:** Equitable distribution of scheduling burden; measurable inclusion equity in live debate.

### C. Sacred Windows & Cultural Calendar
- **No-Fly Zones:** No meetings before 8 AM or after 7 PM local without explicit opt-in and comp-time approval.
  - **Ramadan:** No meetings during fasting hours unless the individual opts in.
  - **LATAM / Other Regions:** Post-lunch low-bandwidth windows are avoided for heavy decisions.
- **Global Calendar:** Mark holidays and observances affecting capacity (Golden Week, Diwali, Ramadan, Eid, Semana Santa, etc.).

**Rationale:** Calendar respect is a retention tool; scheduling over sacred or fasting hours signals that local norms are expendable.  
**Expected Outcome:** 100% of ceremonies scheduled within local business norms unless voluntarily opted-in.

### D. Hybrid Equity
- **One Camera, One Mic Per Person:** No conference-room “bowling alley” audio. Remote participants must distinguish every speaker.
- **Digital-First Artifacts:** All whiteboards and sticky notes exist in a shared digital canvas (Miro/Mural/FigJam). Physical whiteboards are prohibited for hybrid meetings.
- **Video as Optional:** Cameras-off is socially acceptable without penalty.

**Rationale:** Hybrid meetings default to privileging co-located participants; explicit digital-first rules prevent a two-class participant dynamic.  
**Expected Outcome:** Remote contributors possess equal signal and agency.

## IV. CULTURAL BRIDGING TECHNIQUES

*Principle: Inclusion is a behavioral discipline. Cultural dimensions describe populations, not people. Individual self-assessment supersedes national origin.*

### A. Individual Cultural Profiles (Week 1 Activity)
**Replace national profiling with personal mapping.** During onboarding, each team member self-assesses across six dimensions:

- **Communication Context:** Explicit instructions vs. contextual cues.
- **Disagreement Style:** Immediate debate vs. private processing.
- **Decision-Making Preference:** Consensual discussion vs. clear owner decides.
- **Trust-Building Speed:** Tasks first vs. relationship first.
- **Feedback Reception:** Public direct critique vs. private written first.
- **Power-Distance Comfort:** Public challenge acceptable vs. 1:1 with manager/bridge preferred.

**Action:** Aggregate anonymized results into a **Team Working Agreement**. Calibrate rituals accordingly (e.g., if 60% prefer private feedback, default to that).

**Rationale:** National profiling risks stereotyping individuals and overlooking diaspora identities; self-assessment captures actual working preferences.  
**Expected Outcome:** Team Working Agreement published within 3 weeks; <10% of future friction misattributed to “personality” rather than process.

### B. Explicit Definition of Ambiguous Terms
Maintain a living glossary:

- **“Done”:** Merged? Staging tested? Prod deployed? Documented?
- **“Urgent”:** P0 (drop everything) vs. P1 (this week).
- **“Soon” / “ASAP”:** Banned. Use calendar dates.
- **“Yes”:** Means “I hear you” in many contexts. Protocol: *“Please confirm explicit agreement by restating the action item.”*
- **“Feedback round”:** Grammatical edits or architectural overhaul?

**Rationale:** Tech teams assume shared vocabulary that diverges culturally, producing rework from misaligned expectations.  
**Expected Outcome:** Reduced rework and clearer acceptance criteria.

### C. Communication Style Calibration
- **Default to Low-Context Explicitness:** In mixed teams, the burden of clarity lies with the speaker.
- **The Echo Protocol (Opt-In):** Summarize decisions in writing to confirm alignment. Teams may adopt a “silent ascent” deadline (*“Object within 12 hours or we proceed”*).
- **Visual-First Explanation:** Architecture and process changes must include diagrams. Visual logic transcends verbal fluency gaps.
- **Verbal Pacing:** ~130 words per minute; pause after complete thoughts.

**Rationale:** Clarity defaults protect non-native speakers and high-context team members from losing face by asking “obvious” questions.  
**Expected Outcome:** Faster alignment with fewer clarification loops.

### D. Inclusive Rituals & Cultural Liaisons
- **Rotating Facilitation:** Rotate by region to shift power dynamics and surface diverse styles.
- **Food & Context Sharing:** Quarterly async “Taste of Home” (2-minute Loom of a local meal or tea ritual).
- **Cultural Liaisons:** Volunteers from each major hub with **10% protected FTE, a 6-month term limit, and a lightweight job description**:
  1. Advise on local holiday planning.
  2. Serve as a Tier 1 conflict bridge if requested.
  3. Flag charter norms that feel locally infeasible.

**Rationale:** Distributed teams need embedded local expertise, but volunteer roles become unfunded burdens without protected time and term limits.  
**Expected Outcome:** Early detection of locally infeasible norms; sustainable contribution from regional representatives.

## V. CONFLICT ESCALATION PATHWAYS

*Principle: Conflict is data; delay is damage. In distributed teams, conflict often manifests as silence. One culture’s healthy debate is another’s insubordination.*

### A. Tiered Escalation Model (Format-Fluid Tier 1)

| Tier | Stage | Trigger | Owner | Resolution Method | Timeline |
|------|-------|---------|-------|-------------------|----------|
| **1** | **Self-Managed Choice** | Disagreement, missed expectation, perceived slight | Involved parties | **Menu-Based:** (a) Direct Dialogue, (b) Written Exchange, (c) Cultural Bridge mediation | 48 hours |
| **2** | **Structured Mediation** | Tier 1 failed; talking past each other | Neutral peer, Scrum Master, or Cultural Liaison | **Interest-Based Relational (IBR) Session:** Private caucus available for face-saving | 72 hours |
| **3** | **Managerial Intervention** | Timeline impact; repeated pattern; power imbalance | Engineering/Product Manager | Formal mediation; behavioral contract; re-scoping if needed | 1 week |
| **4** | **HR / OD / Executive** | Harassment, discrimination, ethical violation | HRBP / Ombuds | Formal investigation. Investigator must have cross-cultural competence. | Per policy |

**Rationale:** Mandating emotional disclosure frameworks (e.g., NVC) as the default Tier 1 method conflicts with high power-distance and harmony-prioritizing contexts. A menu respects autonomy and cultural safety.  
**Expected Outcome:** 85%+ of conflicts resolved or contained within 72 hours without managerial intervention.

### B. Early Warning Signals
Managers and leads monitor for:

- **Communication Debt:** >48 hours no response to P1 without an OOO notice.
- **Scope Creep via Silence:** Decisions made in DMs to avoid public debate.
- **Public Blame:** “You always/never” language (especially damaging in collective cultures).
- **Proxy Complaints:** Venting to local peers about another timezone (signals the formal channel feels unsafe).
- **Excessive Deference:** Repeated public agreement followed by private reversal.

**Rationale:** Distributed conflict rarely appears as shouting; it appears as withdrawal, shadow decisions, and proxy complaints.  
**Expected Outcome:** Shift from reactive firefighting to predictive friction detection.

### C. De-escalation Protocols for Async Conflict
1. **12-Hour Cool-Off:** A designated lead pauses the thread and moves it to a private doc or voice call.
2. **Assume Positive Intent (API) Reminder:** *“We operate across languages and contexts. Let’s restate the shared goal before continuing.”*
3. **Move to Voice:** If a thread exceeds 5 back-and-forth messages, escalate to a 15-minute video or voice-note exchange. Text strips tone; voice restores humanity.
4. **Face-Restoration Clause:** Public conflict requires public acknowledgment of the solution; apology details remain private if preferred.

**Rationale:** Async text channels amplify misinterpretation and entrench public humiliation.  
**Expected Outcome:** Prevents relationship rupture and preserves psychological safety.

### D. Post-Conflict Learning Review
Within 1 week of Tier 2+ resolution, conduct a **blameless retrospective**:

- What system allowed this to fester?
- Was this personality, cultural mismatch, or process gap?
- Update the Team Working Agreement accordingly.

**Rationale:** Without institutional learning, the same friction recurs under new personnel.  
**Expected Outcome:** Continuous refinement of team norms.

## VI. TRUST-BUILDING EXERCISES

*Principle: Trust is built through micro-moments of consistency and consensual vulnerability—not through extracted disclosure.*

### A. “Working With Me” Manuals (Onboarding Week 1)
Each member publishes a 1-page doc covering work hours, communication style, feedback preferences, power-distance comfort, and optional personal context.

**Privacy Guardrail:** No medical, family, or legally protected disclosures are required. Managers model by sharing first.

**Rationale:** Accelerates the onboarding trust curve by replacing months of guesswork with explicit operating preferences.  
**Expected Outcome:** New hires reach full collaboration velocity faster; reduced early-relationship friction.

### B. Contextual Calendar Transparency
- **Default:** “Show availability only” remains the technical default for GDPR and works-council compliance.
- **Opt-In Norm:** Individuals may share contextual blocks (*“Deep Work,” “School Run,” “Ramadan — low energy until 2 PM”*) to build empathy. Never mandatory.

**Rationale:** Transparency builds empathy, but mandatory calendar openness conflicts with European privacy norms and may violate works-council agreements.  
**Expected Outcome:** Empathy without coercion.

### C. Cross-Timezone Shadowing & Reverse Mentoring
- **Pair Review / Pair Debug:** Monthly cross-region pairing on non-critical work.
- **Reverse Mentoring:** HQ senior staff paired with hub junior staff to learn local cultural and organizational context.

**Rationale:** Builds relational debt so that when P0 blockers arise, team members negotiate with a person, not a timezone. Also redistributes power and HQ-centric bias.  
**Expected Outcome:** Faster incident resolution and stronger lateral trust networks.

### D. Virtual Watercooler Infrastructure
- **Dedicated Channels:** `#wins`, `#life`, `#reading`, `#random`. Leadership must seed with first posts to signal permission.
- **Coffee Roulette:** Automated pairing every 2 weeks for 15-minute non-agenda chats.
- **Team Time Capsule:** Quarterly async photo/video share.

**Rationale:** Distributed teams lose ambient bonding by default; intentional infrastructure replaces hallway collisions.  
**Expected Outcome:** Sustained social cohesion scores across time zones.

### E. Recognition Across Cultural Contexts
- **Ask First:** Onboarding intake covers recognition preference (public shout-out, private note, team meeting, or monetary).
  - *Individualist contexts* often prefer individual recognition.
  - *Collectivist contexts* often prefer team-based celebration to avoid envy or isolation.
- **Timezone-Aware Celebrations:** Rotate ceremony host time (APAC / EMEA / Americas); record all for async viewing.

**Rationale:** Misaligned recognition creates discomfort rather than motivation.  
**Expected Outcome:** Recognition lands as intended, reinforcing retention.

## VII. IMPLEMENTATION PROGRAM: 120-DAY PILOT-TO-SCALE

### A. Governance & Ownership
- **Charter Steward:** A single operational owner (e.g., Global Head of Engineering or Chief of Staff) accountable for compliance, metrics, and quarterly review.
- **Cultural Advisory Board:** ERG leads and regional People Partners advising localization.
- **Review Cycle:** Quarterly or upon team topology changes.

### B. Prioritized Roadmap

| Phase | Timeline | Key Deliverables |
|-------|----------|------------------|
| **Phase 0: Governance & Audit** | Weeks 1–2 | Legal/IT approves tool stack per data-residency rules; bandwidth audit of all hubs; appoint Charter Steward and Cultural Liaisons (10% protected FTE); classify every squad by Topology Tier (1/2/3) |
| **Phase 1: Foundation** | Weeks 3–6 | Publish localized Charter; collect “Working With Me” docs; map Sacred Windows and Global Calendar; deploy EOD handoff template; deploy DM backfill bot; train leads on Tier 1 conflict menu |
| **Phase 2: Pilot** | Weeks 7–10 | Run with **one squad per Topology Tier** (one Tier 1, one Tier 3 minimum); migrate standups to async; institute pre-read policy; run Culture Mapping workshop; launch Coffee Roulette; collect weekly friction logs |
| **Phase 3: Refinement** | Weeks 11–14 | ERG and works-council review; localize Tier 1 conflict menus; adjust rituals that became noise; finalize Pain Score ledger; conduct first blameless retro using new charter |
| **Phase 4: Scale** | Week 15+ | Roll out to remaining squads; quarterly charter review cycle; rotate Cultural Liaisons; measure baseline engagement/sentiment and refine |

### C. Success Metrics & Review Gates

| Gate | Checkpoint | Pass Criteria |
|------|------------|---------------|
| **Gate 0** | End of Week 2 | 100% tool compliance; all squads tiered; liaisons appointed |
| **Gate 1** | End of Week 6 | >90% “Working With Me” completion; bot deployed; zero shadow IT channels active |
| **Gate 2** | End of Week 10 | Pilot squads show 20% MTTD improvement; Pain Score published; <5% live meetings lack pre-read |
| **Gate 3** | End of Week 14 | ERG sign-off; >80% pilot satisfaction; retro process validated |
| **Gate 4** | Week 15+ | Scale authorized; quarterly review cadence established |

## APPENDIX: QUICK-START TEMPLATES & TOOLS

### A. EOD Handoff Template
```
[Baton Pass] – [Name] – [Date/UTC]
✅ Shipped: [Ticket numbers / merged PRs]
🔗 Dependencies / Input Needed: [Framed as collaborative request]
🎯 Next Owner: [@teammate] – [Specific task/decision]
⏳ Awaiting Response: [@name] re: [question]
💬 Alignment Check: [Optional: "Please confirm explicit agreement."]
```

### B. Async Meeting Pre-Read Template
```
Meeting: [Title] | Date: [UTC + all local times] | Topology Tier: [1/2/3]
Goal: [Decision / Info / Ritual]
1. Context (2-min read)
2. Options / Data
3. Proposed Path
4. Questions We Must Answer
5. Async Input: [Link for written comments before live session]
[Attach docs / Loom links]
```

### C. Tier 1 Conflict Format Selection (Menu)
```
Parties: [@name] & [@name]
We have selected Format: [ ] Direct Dialogue  [ ] Written Exchange  [ ] Cultural Bridge
If Direct Dialogue, we agree to: [structured debate / NVC / Other]
If Written Exchange, deadline for response: [Date/UTC]
If Cultural Bridge, liaison: [@name]
Goal: Resolve [specific issue] by [date].
```

### D. Facilitator Calibration Card (Display On-Screen During Live Meetings)
```
□ Pre-read sent 48h ago? (If no, cancel)
□ Speaking pace check: ~130 wpm
□ Paused 7–10 seconds after each question? (Count silently)
□ Explicitly invited each person once before open floor?
□ Chat monitor assigned and surfaced written questions?
□ Recording + transcription started? Backup note-taker named?
□ Cameras-off respected without comment?
```

### E. Topology Tier Quick Reference
```
Tier 1 (≥3h overlap): Core live window + standard ROTATE+
Tier 2 (1–3h overlap): Live decisions only; rotate aggressively
Tier 3 (<1h / zero): Async ceremonies only; live by exception + comp time
```
