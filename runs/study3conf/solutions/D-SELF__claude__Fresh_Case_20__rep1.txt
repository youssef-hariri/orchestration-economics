# SECTION 1: ONE-PAGE STRATEGY SUMMARY

## CORE PILLARS

| PILLAR | DEFINITION | MECHANISM | OUTCOME |
|--------|-----------|-----------|---------|
| **Regulatory Compliance-First Architecture** | All mechanics aligned with binding regulations (Belgium/NL loot-box bans, Korea/China probability disclosure, China real-name enforcement) | Region-locked cosmetic stores; probability tables published monthly; real-name + spending-cap enforcement | Zero app-store removal risk; regulatory authority confidence |
| **Cosmetic Accessibility Equivalence Standard (CAES)** | Every cosmetic acquirable within equivalent time/cost across regions despite different mechanics | Universal "Cosmetic Currency Value" (100–1000+ CC); grind-time audited quarterly; all cosmetics return within 12-month cycle | Players perceive fairness across regions; no "secondary citizen" perception; cross-region guild trust |
| **Cultural Monetization Pillars** | Region-specific spending preferences honored (Korea gacha acceptance, US cosmetics-only preference, Gulf gift-giving sensitivity, Brazil pay-to-win tolerance) | Gacha-centric in Korea/China/Japan; cosmetics-only in Belgium/NL/US; gift-giving event framing in Gulf/Brazil; achievement cosmetics emphasized universally | Engagement + spending aligned to local psychology; not one-size-fits-all imposition |
| **Unified Game Economy** | Cross-region gameplay fairness (no spending advantage in ranked PvP, event rewards equivalent, story progression synchronized) | "Equalized stats" in PvP (cosmetics-only visible); global event calendar with regional cosmetics; simultaneous story rollout across regions | Players perceive "one game, different cosmetics" not "fragmented games"; community cohesion preserved |
| **Advocacy-Group Coordination** | Proactive engagement with player-protection organizations (Consumentenbond, GRR, CGA, FTC, Common Sense Media, IDEC) before launch, not after complaint | Quarterly advisory board meetings; transparency reports exceed legal minimums; pre-launch stakeholder briefings; published engagement protocols | Regulatory authority perceives "good-faith player protection"; reduced enforcement action risk 30–40%; preempted advocacy campaigns |
| **Dynamic Product Governance** | Rapid adaptation to regulatory changes (new spending-cap requirements, probability-disclosure format changes, cultural sensitivity shifts) | Quarterly regulatory check-in; decision tree framework (Appendix D); pre-built cosmetic-store variants (cosmetics-only backup for Belgium/NL, expected-value dashboard for Korea harmonization); 2–4 week deployment latency | Regulatory drift absorbed without emergency patches; maintains compliance headroom 6–12 months ahead of regulation |

## GLOBAL REVENUE MODEL & PLAYER FAIRNESS CONVERGENCE

**Unified Cosmetic Currency Value (CC) Scale** ensures all players perceive equivalent access despite regional mechanism differences:

```
LEGENDARY COSMETIC (1000 CC)
├─ Belgium/NL:     Direct €15 OR 100-hour grind OR battle-pass tier 100
├─ Korea:          ₩9,900 (~€6) direct OR 90-pull gacha (~₩18K expected) OR battle-pass
├─ China:          ¥49 (~€6.50) direct OR 90-pull gacha (~¥240 expected-value) OR battle-pass
├─ Japan:          ¥2,200 (~€15) direct OR 90-pull gacha (~¥33K expected) OR battle-pass
├─ Gulf:           SAR 50 (~€13) direct OR "destiny draw" gacha (1000 CC equivalent) OR battle-pass
├─ Brazil:         R$59 (~€10) direct OR cosmetic gacha OR battle-pass
├─ US:             $12.99 direct OR cosmetic-gacha pull (~$12 expected) OR battle-pass
└─ **Result: All players invest equivalent total effort; fairness perceived globally**
```

**Revenue Sustainability:**
- Belgium/NL: €3–5/month ARPU (battle-pass + direct cosmetics)
- Korea: ₩20–30K/month ARPU (~€12–18; gacha-primary)
- China: ¥40–60/month ARPU (~€5–8; spending-cap constrained)
- Japan: ¥100–150/month ARPU (~€0.67–1; whale-concentrated)
- Gulf: SAR 50–100/month ARPU (~€13–26; status cosmetics)
- Brazil: R$50–100/month ARPU (~€8–17; power-up + cosmetics)
- US: $8–12/month ARPU (cosmetics-primary, battle-pass-heavy)

**Blended global ARU target: $8–12/month** (supports 18–24 month live-service sustainability)

## HOW TO DEPLOY NEW MECHANICS: REGION-LOCK vs. GLOBAL ROLLOUT

```
NEW MECHANIC PROPOSED
│
├─ STEP 1: INVOLVES RANDOMIZATION? (Gacha, cosmetic lottery, loot-box)
│  │
│  ├─ NO → SKIP TO STEP 3 (Deterministic mechanics typically global-safe)
│  │
│  └─ YES → Proceed to STEP 2
│     │
│     └─ STEP 2: LEGAL IN ALL 8 MARKETS?
│        │
│        ├─ NO (e.g., loot-box banned Belgium/NL)
│        │  └─ STEP 2A: Create compliant variant
│        │     ├─ Belgium/NL: Replace gacha → direct purchase + grind-unlock
│        │     ├─ Korea/China: Deploy with probability disclosure
│        │     ├─ Japan/Gulf/Brazil/US: Deploy as designed
│        │     └─ **DEPLOYMENT: Region-lock by IP + server-side purchase validation**
│        │
│        └─ YES (Legal everywhere)
│           └─ STEP 3: AFFECTS GAMEPLAY POWER?
│              │
│              ├─ YES (e.g., weapon stats, character power)
│              │  └─ STEP 3A: Regional pay-to-win tolerance assessment
│              │     ├─ Brazil: High tolerance → can deploy globally (power gacha acceptable)
│              │     ├─ Japan: Medium tolerance → cosmetics-only OK; power-gacha not OK
│              │     ├─ Korea/China/US/EU: Low tolerance → cosmetics-only required
│              │     ├─ Gulf: Sharia-sensitive → no power-gacha framing
│              │     └─ **DECISION TREE RESULT:**
│              │        ├─ If Brazil-only acceptable: REGION-LOCK to Brazil
│              │        ├─ If cosmetics-only acceptable globally: DEPLOY GLOBALLY as cosmetics-only
│              │        └─ If power-gacha needed but region-variant: REGION-LOCK + create cosmetics variant
│              │
│              └─ NO (Cosmetics-only, cosmetic gacha, battle-pass cosmetics)
│                 └─ STEP 4: CULTURALLY ALIGNED?
│                    │
│                    ├─ NO (e.g., cosmetic gacha low-value in Gulf)
│                    │  └─ STEP 4A: Adapt emphasis
│                    │     ├─ Gulf: Make cosmetic gacha optional; emphasize direct purchase + gift-giving events
│                    │     ├─ Belgium/NL: Remove gacha entirely; replace with grind-unlock
│                    │     └─ **DEPLOYMENT: Region-adapted (same mechanic, different framing/emphasis)**
│                    │
│                    └─ YES (Culturally expected)
│                       └─ STEP 5: CROSS-REGION FAIRNESS IMPACT?
│                          │
│                          ├─ NO (Cosmetics-only, aesthetic difference)
│                          │  └─ **DEPLOYMENT: GLOBAL + regional cosmetics (e.g., K-pop skins Korea, anime skins Japan)**
│                          │
│                          └─ YES (Creates unfair FOMO, accessibility gap)
│                             └─ STEP 5A: Add compensatory mechanism
│                                ├─ All regions access equivalent cosmetics within 12 months (rotation guarantee)
│                                ├─ All regions have tooltip explaining regional exclusivity reason (regulatory, cultural)
│                                ├─ All regions receive region-exclusive cosmetics to offset envy
│                                └─ **DEPLOYMENT: GLOBAL with documented fairness compensations**

FINAL DECISION POINT:
├─ **REGION-LOCK:** Isolate mechanic to specific region(s); deploy regional variants in other regions
├─ **GLOBAL + REGIONAL COSMETICS:** Deploy globally; customize cosmetic themes per region
├─ **REGION-ADAPT:** Deploy globally with emphasis differences (cosmetic gacha emphasized in Korea, de-emphasized in Gulf)
└─ **BLOCK:** Do not deploy if regulatory/fairness conflicts unresolvable

REGULATORY CHECK-IN:
├─ Legal team approval (2-week review minimum)
├─ Advocacy board notification (30-day comment window)
└─ Third-party audit scope updated (quarterly rate verification, if applicable)
```
