## STEP 2: YOUR CORE OBLIGATIONS BY TIER

### **TIER 1: STRICT COMPLIANCE (EU, UK, Canada, CO, CT, NY)**

**Before You Deploy:**
- ✓ Obtain independent bias audit (ISO/IEC 42001 certified auditor)
- ✓ File compliance report with regulator (DPA/Attorney General)
- ✓ Document data localization setup (EU/UK/Canada-based servers)

**Ongoing (Every Quarter):**
- ✓ Run bias testing; document disparate impact ratios
- ✓ Maintain immutable audit trail (all hiring decisions logged)
- ✓ Update fairness metrics dashboard (real-time, candidate-visible)

**For Every Candidate:**
- ✓ Send pre-hire AI disclosure (30 days before screening)
- ✓ If rejected: Provide explanation within 45 days
- ✓ Implement human review at finalist stage (mandatory)

**Regulatory Reporting:**
- ✓ Annual audit report to DPA (Q2-Q3)
- ✓ Escalation to regulator if disparate impact detected

**Cost:** €80K–150K annually (independent audits, documentation, compliance overhead)

---

### **TIER 2: MODERATE COMPLIANCE (Illinois, California, Singapore, Japan, South Korea)**

**Before You Deploy:**
- ✓ Internal fairness assessment (vendor self-assessment acceptable)
- ✓ Document bias testing plan
- ✓ Prepare candidate disclosure templates

**Ongoing (Semi-Annual):**
- ✓ Run bias testing; document results
- ✓ Maintain hiring audit trail (12-24 months minimum)
- ✓ Optional: Update fairness metrics dashboard (weekly recommended)

**For Every Candidate:**
- ✓ Send pre-hire AI disclosure (recommended)
- ✓ If rejected: Provide explanation if requested (30-day SLA)
- ✓ Offer human review option (recommended but not required)

**Regulatory Reporting:**
- ✓ None required (unless regulator inquires)
- ✓ Prepare for audit in response to complaint

**Cost:** $10K–30K annually (internal assessments, documentation)

---

### **TIER 3: FLEXIBLE COMPLIANCE (USA Federal, Australia, Brazil)**

**Before You Deploy:**
- ✓ Document your fairness testing approach
- ✓ Set up audit trail (12+ months retention)
- ✓ FCRA compliance if hiring-specific AI (disclosure + adverse action notice)

**Ongoing (Annual):**
- ✓ Retain hiring records (EEOC discovery standard: 1 year minimum)
- ✓ Optional: Internal fairness assessment
- ✓ Human review optional

**For Every Candidate:**
- ✓ FCRA adverse action notice (if applicable: 30–45 days)
- ✓ Explanation of AI use (if requested)
- ✓ Human review available (optional)

**Regulatory Reporting:**
- ✓ None required proactively
- ✓ Respond to EEOC inquiries as they arise

**Cost:** $0–10K annually (standard compliance documentation)

---

## STEP 3: DETERMINE YOUR ACTUAL TIER

**Rule 1:** If you hire in ANY Tier 1 jurisdiction, apply Tier 1 rules globally
- Example: US company with Berlin office → Use Tier 1 for all hiring

**Rule 2:** If you hire in multiple tiers but NOT Tier 1 → Apply highest tier (usually Tier 2)
- Example: Hiring in California + Japan → Use Tier 2 for both

**Rule 3:** If Tier 3 only → Use Tier 3 flexibility
